# 参与此项目

> **待审核译稿（draft）** · 译者：Codex · 人工审核：待定 · [英文参考原文](https://github.com/Open-Source-Research-Initiative/project-template/blob/198dc3deeaf68befa702813e23f6a471fbcaf7bb/CONTRIBUTING.md)

先阅读项目 README 和第一个任务。你可以提问、建议资料、核查引用、评审、写作、分析、编程或建模。

遵循 [OSRI-0.1.0（英文基准）](https://github.com/Open-Source-Research-Initiative/osri/blob/8c39a0a36c0e962060659b1d51f666c367f9464a/governance/contribution-standards.md)。限定任务范围，关联证据，报告已完成的检查，并说明仍需进行的人工评审。记录智能体提供的实质性帮助。

用 issue 跟踪已商定的任务，用拉取请求提交修改。不熟悉 Git 时，可以请维护者协助。由人负责接受工作并授权公开。

遵循[写作](https://github.com/Open-Source-Research-Initiative/osri/blob/main/translations/zh-Hans/governance/writing-style.md)、[翻译](https://github.com/Open-Source-Research-Initiative/osri/blob/main/translations/zh-Hans/governance/translation.md)与[视觉识别](https://github.com/Open-Source-Research-Initiative/osri/blob/main/translations/zh-Hans/governance/visual-identity.md)指南；这些中文页面均为待审核译稿。

需要帮助时，请使用[问答区（Q&A）](https://github.com/Open-Source-Research-Initiative/.github/discussions/new?category=q-a)。资源申请或其他问题涉及保密事项时，请私下联系 [Cole](mailto:cole.lyons@pennmedicine.upenn.edu)。
